# 🏢 Общага-тайкун

Idle-тайкун для **Яндекс Игр**. Вы новый комендант полуразваленной общаги: заселяете студентов,
собираете плату, делаете ремонт, разруливаете хаос (тараканы, пожары, вечеринки, проверки из деканата)
и в итоге переезжаете в новые корпуса — от «Общаги №3» до студгородка.

- Чистый JavaScript + Canvas 2D, **без движков и библиотек**.
- **Вся графика нарисована кодом**: ни одной картинки, никаких проблем с правами и модерацией.
- **Звуки синтезируются** через WebAudio — тоже без файлов.
- Архив для Яндекса весит **≈ 90 КБ**.
- Русский и английский язык, облачные сохранения, управление пальцем и мышью.

## Как запустить локально

Нужен любой локальный веб-сервер (из-за `file://` браузер может ругаться):

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

Без Яндекса игра сама включает «мок» SDK: реклама показывается заглушкой на 1–1,5 секунды
и выдаёт награду, сохранения пишутся в `localStorage`.

## Сборка архива для Яндекса

```bash
python tools/build.py
```

Получится `dist/obshaga-tycoon-v<версия>.zip` — его и загружаешь в консоль разработчика.
Скрипт заодно проверяет, что все файлы на месте и игра не тянет ничего с внешних доменов,
и печатает чек-лист перед публикацией.

## Баланс

Все цифры живут в `js/config.js` (цены, доходы, персонал, события, престиж).
Проверить, как изменение скажется на темпе игры, можно симулятором — бот играет «жадно»
и печатает, на какой минуте открываются этажи, персонал и сколько звёзд даст престиж:

```bash
node tools/balance_sim.js 120                    # 120 минут игры
RUNS=5 node tools/balance_sim.js 600             # 5 переездов подряд
OVERRIDE='{"UPG_GROWTH":1.2}' node tools/balance_sim.js 90   # проверить другую цифру, не трогая конфиг
```

Текущий темп (идеальный бот, живой игрок примерно в 1,5–2 раза медленнее):
2-й этаж — ~5 мин, 3-й — ~17 мин, 4-й — ~36 мин, 5-й — ~73 мин. Следующие корпуса
проходятся за 25–40 минут, и время не схлопывается в ноль (звёзды считаются от заработка
за всё время, корень 4-й степени — как ангелы в AdVenture Capitalist).

## Что есть в игре

| Система | Как работает |
|---|---|
| Комнаты | 15 комнат (5 этажей × 3), у каждой 50 уровней. Каждые 10 уровней — **капремонт** и новый вид: голые стены → двухъярусные кровати → ремонт с ковром на стене → холодильник, Wi-Fi, гирлянда → люкс с приставкой и кондиционером. |
| Плата | Копится в «мешочке» над комнатой (до 30 сек дохода), её собирают тапом. Тап по комнате/студенту даёт ещё и монеты за клик. |
| Кухня | По одной на этаж, +10% к доходу этажа за уровень. Иногда горит. |
| Душевая / Прачечная / Качалка / Вахта | Репутация / пассивный доход / дорогие студенты / сколько часов копится оффлайн-доход. |
| Персонал | Тётя Валя (автосбор + оффлайн), Баба Зина (мусор), Михалыч (поломки), староста Костя (заселение и +% к плате). Переезжают с вами в новый корпус. |
| Репутация | 0–100, тянется к цели (чистота, душевая, качалка, поломки). Открывает студентов: первокурсники → старшекурсники → магистры → иностранцы. |
| События | Тараканы, пожар на кухне, вечеринка (выбор: разогнать / штраф / договориться за видео), проверка из деканата, посылка от мамы, отключили интернет, отключили горячую воду, кот Семён. |
| Престиж | «Переезд в новый корпус»: звёзды коменданта, +10% к доходу за звезду навсегда. 4 оформления корпусов, дальше «Студгородок II, III…», прошлые корпуса стоят на фоне. |
| Цели | 27 обучающих целей + бесконечные генерируемые. Подсказки и шутки — от тёти Вали. |
| Время суток | 8-минутный цикл: закат, ночь со светом в окнах и неоновой вывеской, студенты ночью спят. |

## Реклама (заработок)

Только через SDK Яндекса, всё по правилам площадки:

- **За награду**: ×2 доход на 5 минут (копится до часа), ×2 оффлайн-доход при входе,
  мгновенное решение события, бесплатное улучшение раз в 3 минуты, ×3 посылка от мамы,
  «договориться» на вечеринке.
- **Межстраничная**: только на переходах — постройка этажа и переезд, и не чаще раза в 3 минуты
  (поверх ограничения самого Яндекса).
- **Sticky-баннер**: включается в консоли, кода не требует — рекомендую включить.

Во время рекламы игра ставится на паузу, звук выключается, вызывается `GameplayAPI.stop()`.

## Требования Яндекса, которые уже выполнены

- `LoadingAPI.ready()` после загрузки, разметка `GameplayAPI.start()/stop()`.
- Пауза и выключение звука при сворачивании вкладки, во время рекламы и по событиям
  платформы `game_api_pause` / `game_api_resume`.
- Язык определяется автоматически (`ysdk.environment.i18n.lang`), можно сменить в настройках.
- Облачные сохранения (`player.setData`) + локальные через `ysdk.getStorage()`;
  при входе берётся более свежее.
- Нет контекстного меню, выделения текста, прокрутки и зума страницы.
- Никаких внешних ресурсов — только `/sdk.js`.
- Лидерборд `stars` (необязательно: создай в консоли с таким техническим именем).
