# 🚆 3goth2002 Surfers — Тригот против Охранника

3D-раннер (личный проект «по приколу», не для публикации): три полосы, поезда, барьеры, рампы на крыши вагонов,
монеты, бонусы, готический вечер с багровым небом. За Триготом гонится Охранник с топориком:
споткнулся дважды подряд — поймали.

Персонажи собраны по аутфитам: Тригот — рыжий шег, красный бомбер SUPREME с костями и кожаными рукавами,
джинсы в заплатках, берцы; Охранник — чёрный шег с пробором, кожанка, кожаные штаны, берцы, топорик.

- Three.js (лежит в `js/vendor`, ничего не грузится с внешних доменов).
- **Вся графика собрана кодом**: персонажи, поезда, дома, деревья; принты и джинса нарисованы на canvas. Ни одной картинки.
- Звуки и музыка синтезируются WebAudio.
- Архив ≈ 200 КБ. RU/EN, облачные сохранения, свайпы / клавиатура.

## Запуск

```bash
cd runner && python -m http.server 8000   # открыть http://localhost:8000
```

Без Яндекса включается мок SDK: реклама — заглушка на ~1 с, сохранения в `localStorage`.

## Сборка для Яндекса

```bash
python runner/tools/build.py   # → dist/3goth2002-surfers-v<версия>.zip
```

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Полоса влево/вправо | ← → / A D | свайп в сторону |
| Прыжок | ↑ / W / пробел | свайп вверх |
| Кувырок (в воздухе — резко вниз) | ↓ / S | свайп вниз |
| Пауза | Esc / P | кнопка II |

## Механика

- **Красно-белый барьер** — перепрыгнуть. **Жёлто-чёрный щит сверху** — кувырок под ним.
- **Поезд** — обойти или забежать на крышу по **рампе**. С суперкедами можно запрыгнуть на поезд сразу.
- **Встречный поезд** (с горящими фарами) едет на тебя — уходи с полосы.
- Удар сбоку при смене полосы = спотыкание, контролёр догоняет на 4 секунды. Второй раз за это время — поймали.
- Бонусы: магнит, очки x2, суперкеды, щит (спасает от одного лобового удара). Длительность прокачивается за монеты.
- Скины: Тригот (бесплатно), Тригот: Ночь 2000, Тригот: Пинк 5000.

## Реклама (обязательное для Яндекса уже сделано)

- `LoadingAPI.ready()` после загрузки, `GameplayAPI.start/stop` на забег/паузу/смерть.
- Rewarded: «Продолжить» (1 раз за забег) и «Удвоить монеты».
- Interstitial: раз в 2 забега при переходе «Ещё раз» / «Меню».
- Пауза и выключение звука по `game_api_pause` и при сворачивании вкладки.
- Лидерборд `railrushScore` — создай его в консоли разработчика, иначе вызов просто молча игнорируется.

## Где что

| Файл | Что внутри |
|---|---|
| `js/config.js` | весь баланс: скорость, прыжок, цены, бонусы, персонажи (цвета) |
| `js/characters.js` | персонажи: геометрия, принты/джинса на canvas, анимация |
| `js/models.js` | поезда, барьеры, окружение, небо |
| `js/world.js` | генератор трассы (шаблоны секций), монеты, встречные поезда |
| `js/main.js` | физика и столкновения, камера, UI, магазин, реклама |
| `js/sdk.js` | обёртка Яндекс SDK + мок |

Новый скин = запись в `CFG.SKINS` (цвета, надписи на бомбере `text` / `backText`) + строки `skin_<id>` / `sd_<id>` в `js/i18n.js`.

В консоли браузера доступен `__rr` (состояние игры, `__rr.tick(dt)` для прогонки симуляции без рендера).
